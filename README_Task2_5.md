# Employee Registration Shell Script
Documentation for creating, editing, making executable, and running an interactive bash script (employee.sh) that registers and displays employee details.

## Overview
This project features a simple Shell script that prompts the user for employee information (Name, Age, Department, Salary) and formats the entered data into a clean text summary upon execution.

## Setup Instructions
### 1. Create the Script File
Create a new file named employee.sh:
```bash
create_file employee.sh
```

### 2. Edit the Script Contents
Open the script using nano:

```bash
nano employee.sh
```
### 3. Grant Execution Permissions
Make the script executable using chmod:

```bash
chmod +x employee.sh
```

### 4. Run the Script
Execute the script from your terminal:

```bash
./employee.sh
```
