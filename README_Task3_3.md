# 🔐 Assignment 3 - Password Strength Checker

## 📌 Description
This Bash script checks the strength of a user-entered password based on specific criteria.

## ⚙️ Features
The script verifies if the password contains:
- At least 8 characters
- Uppercase letter
- Lowercase letter
- Digit
- Special character

Then it displays a detailed report and overall strength.

## 🚀 How to Run

1. Open terminal
2. Navigate to the folder
3. Run:

chmod +x password.sh  
./password.sh

## 🧠 Concepts Used
- String length (`${#var}`)
- Pattern matching (regex)
- Conditional statements (`if`)
- Variables
