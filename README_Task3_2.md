# 🐧 Assignment 2 - Mini Linux System Monitor

## 📌 Description
This project is a menu-driven Bash script that acts as a simple Linux system monitoring tool.

## ⚙️ Features
The script provides a menu with the following options:
1. Show Date
2. Show Uptime
3. Show Logged Users
4. Show Current Directory
5. Show Disk Usage
6. Show Memory Usage
7. List Files
8. Exit

Each option executes a specific Linux command.

## 🚀 How to Run

1. Open terminal
2. Navigate to the folder
3. Run:

chmod +x monitor.sh  
./monitor.sh

## 🧠 Concepts Used
- Functions
- `case` statement
- `while` loop
- Variables
- Command substitution

## 💡 Notes
- The menu repeats until the user chooses Exit
- Each feature is implemented in a separate function
