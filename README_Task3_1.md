# 🧮 Assignment 1 - Arithmetic Operations

## 📌 Description
This Bash script asks the user to enter two integers and performs basic arithmetic operations on them.

## ⚙️ Features
The script calculates and displays:
- Sum
- Difference
- Multiplication
- Division
- Modulus

## 🚀 How to Run

1. Open terminal
2. Navigate to the folder
3. Run the following commands:

chmod +x arith.sh  
./arith.sh

## 🧠 Concepts Used
- User input (`read`)
- Variables
- Arithmetic operations
- Output using `echo`
